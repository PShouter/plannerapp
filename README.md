# PlannerApp

Полностью рабочее Android-приложение-планировщик (MVP) на **Kotlin + Jetpack Compose**.

## Что реализовано
- 5 экранов с нижней навигацией: Главная, Календарь, TODO, Дневник, Привычки.
- Локальное хранение через Room.
- Добавление/просмотр/изменение основных сущностей:
  - события календаря,
  - задачи (выполнение и архив),
  - записи дневника (рейтинг + фото URI),
  - привычки и отметки ✅/❌ по датам.
- Локальные напоминания через WorkManager.

## Запуск
1. Откройте проект в Android Studio (Giraffe+).
2. Убедитесь, что установлен Android SDK 34.
3. Выполните Gradle Sync.
4. Запустите `app` на эмуляторе/устройстве (Android 8.0+).

## Примечания
- Ввод дат сделан в текстовом формате `YYYY-MM-DD` для MVP.
- Интеграция с Google Calendar не включена в текущий MVP, но архитектура для расширения подготовлена.

- Product concept: see `app_spec_ru.md`.
