# PlannerApp — концепт Android-приложения

## 1) Позиционирование
**PlannerApp** — минималистичный личный планировщик «всё в одном»: календарь, напоминания, todo, дневник и трекер привычек.

## 2) Экранная структура

### Главная страница (Dashboard)
Содержит краткую сводку из всех разделов:
- Календарь на неделю.
- Ближайшие напоминания.
- TODO-лист на сегодня.
- Небольшая успокаивающая фотография.
- Мотивирующая цитата.

> На старте блоки фиксированные. В будущих версиях — персонализация и перестановка блоков.

### Страница календаря
- Просмотр дней/событий.
- Интеграция с внешними календарями (Google Calendar и др. через системный провайдер/CalDAV).
- Кнопка **добавления события** в правом нижнем углу (FAB).
- Тап по конкретному дню открывает подробности дня.
- Для событий можно выставлять напоминания.

### Страница TODO
- Список невыполненных задач с группировкой по дням.
- Отдельный раздел для архивных/выполненных задач.
- У задач есть напоминания.
- Задачи синхронно отображаются в календаре.

### Страница личного дневника
- Записи по дням.
- Добавление фото в запись.
- Оценка дня по 5-балльной шкале (звёзды).
- Базовое форматирование текста записи.

### Страница трекера привычек
- Добавление привычек по кнопке «+».
- Привычки перечислены столбиками/строками с отметками выполнения.
- Для каждого дня можно проставлять ✅/❌ по привычке.
- Тап по привычке открывает её подробную карточку (статистика, заметки, цель).

## 3) Минималистичный UI-гайд
- Нейтральный фон, акцентный цвет 1–2 оттенка.
- Плоские карточки, мягкие тени, много «воздуха».
- Шрифты без засечек, крупные заголовки, короткие подписи.
- Иконки одного стиля (outline/rounded).
- Темы: светлая + тёмная.

## 4) Модель данных (MVP)
- **UserSettings**: тема, настройки главной страницы (в будущем), часовой пояс.
- **Event**: id, title, description, startAt, endAt, reminderAt, sourceCalendar.
- **Task**: id, title, note, dueDate, status(todo/done/archived), reminderAt, linkedEventId.
- **DiaryEntry**: id, date, text, rating(1..5), photoUris[].
- **Habit**: id, title, description, createdAt, targetType.
- **HabitMark**: id, habitId, date, status(done/missed/skipped).

## 5) Навигация
Нижнее меню (Bottom Navigation):
1. Главная
2. Календарь
3. TODO
4. Дневник
5. Привычки

## 6) Напоминания и уведомления
- Локальные уведомления через WorkManager/AlarmManager.
- Общий центр напоминаний на главном экране.
- Для задач/событий — настраиваемые напоминания (за 10 мин, 1 час, 1 день и т.д.).

## 7) Этапы релиза
### MVP
- Все 5 экранов.
- CRUD для событий, задач, дневника, привычек.
- Локальные напоминания.
- Виджет-сводка на главной странице.

### v1.1+
- Кастомизация главной страницы.
- Интеграция с Google Calendar.
- Статистика привычек (серии, проценты выполнения).
- Резервное копирование/синхронизация.

## 8) Технический стек (рекомендация)
- **Kotlin + Jetpack Compose**.
- Архитектура: **MVVM + Clean (упрощённо)**.
- Хранение: **Room**.
- Фоновые задачи: **WorkManager**.
- DI: **Hilt/Koin**.
- Медиа: Coil/Glide для фото в дневнике.

## 9) Критерии готовности MVP
- Пользователь может добавить/изменить/удалить:
  - событие в календаре,
  - задачу,
  - запись дневника,
  - привычку и отметки выполнения.
- Напоминания приходят вовремя.
- Главный экран показывает актуальную сводку.
- Интерфейс соответствует минималистичному стилю.
